# bridge64: frozen

This is part of the 64-bit path. See [buildroot64/STATUS.md](../buildroot64/STATUS.md).

`src/` is a local clone of [webosbrew/webos-bridge-64to32](https://github.com/webosbrew/webos-bridge-64to32) v0.0.8. It is not versioned here.

`patches-zip/bridge-64to32-v0.0.8-patches` holds a fork's patch series of 12 patches. All of them apply with `git am`.

The build recipe is in [docs/FINDINGS.md](../docs/FINDINGS.md).
